## Data-quality notes, not new listings

1. **Dublin Stage School (Killiney) looks like an existing duplicate.** Id 410 has address "St. John's National School, Church Road, Killiney, Co. Dublin" and id 1113 has address "Killiney, Dublin" — same business, same town, one row with a real address and one with a vague placeholder. Suggest consolidating rather than adding a third Killiney row.
2. **Ballybrack FC (Coolevin, Ballybrack)** sits just outside all eight target towns technically, but the club explicitly serves Killiney, Loughlinstown, Cabinteely and Shankill. Listed in both the Killiney and Loughlinstown tables above for area context — it's one business/one row, add at most once.
3. **Kilbogget Park, Cabinteely** already hosts two DB entries (Cabinteely GAA id 459, Cabinteely Athletic Club id 424). The two new candidates found there (Cabinteely FC, FoxCab GAA) are different organisations/sports at the same shared venue — consistent with how the DB already handles shared multi-club grounds elsewhere.
4. **MorningStar Dojo (Karate)** is one company running weekly kids karate at two different venues — GSSR Ballyogan (Stepaside/Sandyford border, Dublin 18) and ETNS Cherrywood (Carrickmines/Loughlinstown border). Listed once in each town's table since both are genuinely separate class sessions, similar to how Little Kickers/Turtle Tots get one row per venue — but note it's a single company, so double check whichever gets added doesn't duplicate class-type/description text.
5. **Leopardstown and Carrickmines already have relatively solid coverage** (5 and 3 rows respectively, matching or close to the confirmed-gap threshold) — fewer genuinely new, independently-verifiable candidates turned up for these two than for Deansgrange, Cabinteely, Glenageary and Loughlinstown, which had closer to zero coverage going in.
6. **Session budget note:** this research pass exhausted the available web-search quota partway through the last few towns (Leopardstown, Carrickmines, Deansgrange in particular got fewer follow-up queries than the earlier towns). Treat the "no candidates found" and "checked but excluded" notes for those sections as provisional rather than exhaustive — a follow-up pass with fresh search budget would likely turn up more, especially for Leopardstown.
